Overview
What I Built

Growth OS is a complete personal growth operating system — built to solve the core problem that learners face: scattered tools. Most people use five or six apps for planning, resources, AI help, notes, and tracking. Growth OS consolidates all of that into one authenticated workspace.

At its core is an Adaptive Roadmap Engine that takes a user's goal, domain, available hours per day, and target date — then generates a multi-phase roadmap with milestones, checkpoints, and AI-guided intensity levels. The Planner module converts each roadmap into day-by-day execution maps with task types (Learn, Practice, Revise, Build, Reflect), curated resource links, and milestone checkpoints.

The AI Mentor runs on a dual-model architecture: Gemini 2.5 Flash as primary with OpenAI GPT-4.1 Mini as fallback. It supports four specialized modes — Study Help, Career Advice, Project Review, and Exam Strategy — and maintains persistent conversation threads per user in Firestore, so no context is ever lost.

The Portfolio Vault stores projects, certificates, notes, GitHub links, and uploaded files against Firebase Storage. Analytics track consistency trends, productivity output, streak cycles, weak areas, and roadmap health signals. The entire platform is also packaged as a native Android and iOS app via Capacitor.

Key Highlights
🗻

Adaptive Roadmap Engine

Users set a goal, domain, hours per day, and target date. The system generates multi-phase roadmaps with milestones, dynamic intensity levels, and AI-guided checkpoints.

📅

Planner & Weekly Pages

Converts roadmaps into day-by-day execution schedules with task types (Learn, Practice, Revise, Build, Reflect), curated resource links, and milestone checkpoints.

🤖

Dual AI Mentor

Gemini 2.5 Flash as primary with OpenAI GPT-4.1 Mini as fallback. Four specialized modes with persistent conversation threads stored per-user in Firestore.

📚

Resource Intelligence

AI-ranked curated resources (YouTube, courses, PDFs, practice sets) organized by domain — with career direction snapshots and next proof-of-work suggestions.

🎉

Portfolio Vault

Store projects, certificates, notes, and GitHub links with file upload to Firebase Storage. Every asset is linked to the goal that generated it.

📈

Analytics & Gamification

Consistency trends, productivity charts, streak cycles, weak area detection, roadmap health signals, achievement badges, and a level progression system.

📱

Cross-Platform Mobile

Capacitor-based native packaging for Android and iOS — wrapping the deployed web app in a native shell with dynamic environment URL injection.

🔒

Production-Grade Architecture

End-to-end TypeScript, Firestore transactions for concurrent safety, React 19 with useTransition and useDeferredValue, and centralized error handling with optimistic UI.
