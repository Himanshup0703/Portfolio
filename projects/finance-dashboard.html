Overview
What I Built

Finance Dashboard is a full-stack personal finance management application built to give users complete visibility and control over their financial life. It combines real-time transaction tracking, intelligent budgeting, goal monitoring, and an AI-powered copilot — all in a single responsive dark-themed interface.

The backend is built on Node.js with Express.js and MongoDB, with Mongoose ODM handling data models for Users, Transactions, Budgets, Goals, Timeline Entries, Focus Items, and Reflections. All authentication uses JWT tokens with bcrypt hashing, providing enterprise-grade security and proper per-user data isolation.

The AI Finance Copilot reads the user's live ledger, budgets, goals, and monthly trends in real time, then generates contextual financial advice and answers questions like "How am I doing?" in plain language. The analytics engine surfaces spending trends, top categories, daily averages, and next-month expenditure predictions.

The project involved full Indian Rupee (₹) localisation, fixing database persistence for all growth features, resolving authentication connectivity issues, and migrating branding from Growth Analyzer to Finance Dashboard.
